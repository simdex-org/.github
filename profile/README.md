Simdex is an open-source organization and community: a digital workshop where developers, modders and tinkerers build tools that make other people's lives easier. Everything we make can be used, studied and improved by anyone.

## What we build

| Pillar | What lives here |
| --- | --- |
| **Games and modding** · `games` | Indie games, mods, graphics libraries and open assets, built with accessible engines and tools like Godot, Blender and Bevy. Game mechanics, mod translations, simulation tools and community expansions. |
| **Tools and CLIs** · `cli` | Automation, command-line programs, scripts, optimizers and system utilities. Small tools that solve specific problems and stay lightweight, fast and transparent. |
| **Extensions and plugins** · `ext` | Browser extensions, IDE plugins (like VS Code) and add-ons for game engines and design software. Making the platforms people already use more powerful. |

## How we work

- **Open collaboration.** Anyone can propose an idea, open a pull request or report a bug. Simdex doesn't belong to any single person.
- **Practical value.** We favor tools that work and help right now over theoretical perfection. If it solves a real problem, however small, it's worth building.
- **Accessibility and learning.** Simdex is also a place for mentorship. New developers gain experience by contributing to real projects of every size and stack.

## Get involved

1. Pick a repository that interests you and look for issues labeled `good first issue`.
2. Open an issue to propose an idea, ask a question or report a bug.
3. Send a pull request. If it's your first contribution, say so in the description and we'll review it with you.
